# taskflow-web

Web app for a Todoist Pro-style task manager.

## Initial Scope
- Inbox
- Today
- Upcoming
- Projects
- Sections
- Tasks and subtasks
- Priorities
- Labels
- Due dates and recurring dates

## Planned Stack
- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Zustand

## Branch Strategy
- main: stable
- develop: integration
- feature/*: active work
